# LifePlan App

保険・FP向けのライフプランニングWebアプリ（単一HTMLファイル）。
面談時にファイナンシャルアドバイザーが顧客と一緒に使うことを想定した、
キャッシュフロー表・保障設計・住宅資金・教育資金などを試算できるツールです。

## 構成

- `LifePlan.html` … アプリ本体（HTML/CSS/JS 単一ファイル、外部ライブラリはCDN読み込み）
  - Chart.js（グラフ描画）
  - jsPDF / html2canvas（PDF出力）

## 使い方

1. `LifePlan.html` をブラウザで直接開くだけで動作します（サーバー不要）。
2. 入力内容はブラウザのローカルストレージに自動保存されます。
3. 「JSONエクスポート／インポート」機能でデータのバックアップ・引き継ぎが可能です。
